# Issue 35 infrastructure-validation dataset

This directory preserves the 30-search smoke-test snapshot produced before the
full experiment: five positions, three required budgets, and two repetitions.
It validates the runner, trial replay, integrity checks, frozen
`plan_signature` version 1, and aggregate generation. Its sample size is not
adequate for strategic-convergence conclusions and it must not be combined
with the configured 30-repetition full dataset.
